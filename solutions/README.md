# ⚠️ Corrections — à consulter après avoir essayé

Ces fichiers sont des corrections possibles pour chaque TP décrit dans
`TP.md`. Ce ne sont **pas les seules bonnes réponses** — GitHub Actions
laisse pas mal de liberté dans la façon d'organiser un pipeline.

Pour les utiliser réellement dans ton repo, copie-les dans
`.github/workflows/` et adapte `<TON-USER>` avec ton pseudo GitHub.

Ordre de lecture recommandé : `tp1-ci-lint-test.yml` →
`tp2-cache-artifacts.yml` → `tp3-docker-build-push.yml` →
`tp4-environments-deploy.yml` → `tp5-security-codeql.yml` →
`tp6-reusable-workflow.yml` (+ `tp5-dependabot.yml`).
